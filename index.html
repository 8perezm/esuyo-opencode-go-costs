Get the most value from OpenCode Go

Every model on the Go $10 plan comes with a different usage allowance, which makes them hard to compare. So this page lines them all up against one everyday example: around 100 million tokens of coding work, where most of it reuses things the model has already seen. Change the numbers below to match how you work — the whole table updates instantly, all right here in your browser.

How to read: “Cost” is dollars of allowance consumed by the workload above. “% of $10 cash” = cost ÷ 10 (cash-equivalent). “% of allowance” = cost ÷ that model’s Go allowance (e.g. $3.36 on a $60 allowance = 5.6%, ≈17.9 blocks per month). Values >100% mean the workload does not fit in one $10 subscription for that model.
Assumptions: input tokens only; output tokens excluded (coding agents are input-heavy and outputs vary). Tiered rows (context-size / peak / off-peak) are listed separately as in the official table. Beam Free = $0 (limited time). Prices are built into this page, so it works offline — just open the file. Press “↻ Refresh from source” to fetch the latest Go-plan table from the OpenCode Go pricing docs; the table updates in place and fresh prices are remembered for an hour. To update the built-in snapshot itself, edit the MODELS list in index.html. “Tokens / sub” is the total input tokens the subscription’s allowance buys at the current hit rate (allowance ÷ blended $/1M price; updates when you change the hit rate). Form selections (search, tokens, hit rate, free-models toggle, column visibility, sort column and direction) are remembered in this browser via localStorage.
